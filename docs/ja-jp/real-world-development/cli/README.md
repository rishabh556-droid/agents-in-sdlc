**[GitHub Copilot CLI][about-copilot-cli]** を使うと、ターミナルで GitHub Copilot をエージェント型コーディング アシスタントとして利用できます。コードベースを調査し、コードを生成し、コマンドを実行し、外部ツールに接続できます。コマンド ラインから操作できるため、グラフィカル エディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys の作業を一連のワークフローとして進めます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、プロジェクトを確認します。
2. 星評価の変更を小さく行い、ブラウザーでレビューして、最初のプルリクエスト (PR) を手動でマージします。
3. フィルター機能の issue を起点に、Plan モードで実装方法を決め、Autopilot モードで作成して、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルター機能に適用します。
5. 既存の `quality-checks` スキルをカスタマイズして、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルター機能を確認します。
7. QA カスタムエージェントを作成し、要件、カバレッジ、検証の根拠をレビューします。
8. フィルター機能の変更全体を確認し、Agent Merge を使って PR をマージします。
9. コンテキスト、モデル、共有、任意の cloud agent への委任に役立つスラッシュ コマンドを確認します。

ワークショップでは、星評価とフィルター機能の 2 つの PR を作成します。フィルター機能の PR には、指示の更新、スキルの更新、QA プロファイル、テストを含めます。フィルター機能と品質確認のワークフローでは、同じ会話とブランチを使い、各ツールを学びながら作業を積み上げます。

## 前提条件

このワークショップに参加する前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランを利用できる GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンド ラインの基本的な知識

> [!TIP]
> 有料プランを利用していませんか？認証済みの学生は、[GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使う場合は、管理者が Copilot CLI を有効にしていることを確認してください。
